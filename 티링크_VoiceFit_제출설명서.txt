티링크 Voice-Fit — 상담을 신청한 그 회사만을 위한 홍보물 생성기
제출 설명서

==================================================
0. 한눈에 보기
==================================================
- 과제: 티링크의 제품과 기술적 차별점을 AI가 분석하고, 현장 사진과 제품 정보로 고객의 관심을 끄는 홍보 콘텐츠를 자동 생성하는 마케팅 솔루션
- 한 줄 요약: 이미 손을 든 고객(상담신청·문의 전화)에게, 그 회사의 말과 사진으로 만든 1:1 맞춤 광고를 보낸다.
- 입력: ① 티링크 홈페이지 상담신청서 ② 티링크 AI 녹취의 문의 통화 STT ③ 고객이 보낸 사무실·단자함 사진 ④ 티링크 설치 현장 사진 ⑤ 티링크 6개 솔루션 정보
- 출력: 고객 진단, 맞는 솔루션, 추천 구성과 예상 견적, 설치 형태 판단, 발송 타임라인, 맞춤 MMS 광고, 1장 제안서(+메일), SNS 카드뉴스 6장
- 링크
  · GitHub 저장소: https://github.com/everly-cloud/tlink-voice-fit
  · 데모(claude.ai 아티팩트): https://claude.ai/artifact/M4TLqxykuU9R63Fzc1b98n
  · 시연 영상: (유튜브 URL 기입)

==================================================
1. 문제
==================================================
티링크는 8명 규모의 B2B 통신·AI 녹취 기업으로, 영업 담당자가 마케팅까지 겸합니다.
- 홈페이지 상담신청서와 대표번호(1877-3836)로 관심 고객이 계속 들어오지만, 답변은 매번 비슷한 일반 안내로 나갑니다.
- 고객이 신청서와 통화에서 이미 말한 고민("점심시간에 전화를 못 받는다", "단자함이 좁다")이 홍보물에 반영되지 않습니다.
- 1,000여 개 기업 설치 경험과 현장 사진이 있지만, 고객마다 맞는 사례를 찾아 붙이는 데 시간이 듭니다.
- 홈페이지에서 "현장 사진 몇 장만 보내주셔도 설치 방법과 비용을 안내해 드립니다"라고 약속하지만, 이를 빠르게 처리하는 도구가 없습니다.

==================================================
2. 누구를 타깃으로, 왜 여기에 집중했나
==================================================
- 사용자: 티링크 영업·마케팅 겸임 담당자
- 홍보물을 받는 고객: 상담신청서를 남겼거나 문의 전화를 건 '관심 고객'
- 집중한 이유
  · 모르는 잠재 고객에게 보내는 광고보다, 이미 관심을 보인 고객에게 정확한 답을 빨리 보내는 쪽이 계약 가능성이 높습니다.
  · 관심 고객은 신청서·통화·사진으로 자기 상황을 이미 말해 줬습니다. AI가 개인화할 재료가 가장 풍부한 대상입니다.
  · 티링크는 고객 통화를 녹음하고 STT로 요약하는 회사입니다. 자사 제품이 만든 데이터가 그대로 마케팅 재료가 된다는 점이 다른 회사가 흉내 내기 어려운 차별점입니다.

==================================================
3. 입력 데이터
==================================================
(1) 상담신청서 — 티링크 홈페이지 상담신청 양식과 같은 항목
    회사명, 담당자명, 연락처, 이메일, 관심 솔루션 1·2(6개 중 선택), 문의 내용,
    간편 견적 계산기 선택값(IVR, 콜백, 티링크비즈 A·B·C 타입, 상담원 수, 종합리포트)
(2) 통화 녹취(STT) — 티링크 AI 녹취가 기록한 문의 통화 텍스트. 상담신청 없이 전화만 한 고객도 포함
(3) 고객 사무실 사진 — 단자함·전화기·랙 사진. AI가 이미지를 직접 보고 설치 형태를 판단
(4) 설치 현장 사진 — 홈페이지 설치 사례 11장, 분야(공공·복지, 금융, 교육, 의료, 기업)와 설치 형태 태그
(5) 솔루션 정보 — tlinkcrm.com의 6개 솔루션 페이지를 읽고 정리한 소개·기능·근거 수치·잘 맞는 고객·가격
(6) 폭주 시기 — 분야별 전화가 몰리는 시기(예: 의료 12월 독감철, 교육 3월·9월 학부모 상담 주간)

데이터는 엑셀 1개(상담접수·솔루션정보·폭주시기·사진목록 4개 시트)와 사진 폴더로 관리합니다.
접수가 늘어나면 엑셀에 한 줄, 사진이 늘어나면 폴더에 파일과 사진목록 한 줄을 추가하면 됩니다.

==================================================
4. 동작 순서
==================================================
1) 데이터 연결: 상담 DB 엑셀과 현장 사진 폴더를 불러옵니다.
2) 접수함: 접수 목록이 최신순으로 쌓이고, 접수경로(상담신청/통화 녹취/사무실 사진) 표시, 검색·분야 필터를 제공합니다.
3) 접수 선택: 신청서 내용, 계산기 선택 구성과 금액, 통화 녹취를 확인하고 고객 사무실 사진을 추가할 수 있습니다.
4) 생성: AI가 접수 한 건, 솔루션 정보, 설치 형태 기준, 사진 목록, 폭주 시기를 함께 분석합니다.
5) 결과 확인 후 문구를 복사해 발송합니다. 발송은 담당자가 검토한 뒤 직접 합니다.

==================================================
5. AI가 분석하는 것 (결과 화면)
==================================================
- 고객 진단: 분야, 규모, 우선순위(P1 예산·시점 언급 / P2 관심 높음 / P3 정보 수집), 요약, 고객이 실제로 한 말, 담당자 다음 행동
- 맞는 솔루션: 6개 중 핵심·추가 제안 2~3개와 이유. 고객이 고른 관심 솔루션이 맞지 않으면 그 이유도 제시
  (예: 정형외과가 통화에서 "외국인 환자"를 언급 → 티링크 온 AI 대면통역 추가 제안)
- 추천 구성과 예상 견적: AI는 구성만 정하고 금액은 홈페이지 요금표로 화면이 계산. 고객이 계산기로 고른 구성과 나란히 비교
- 설치 형태: 스탠드형 / 렉거치형 / 미러링스위치허브 중 판단, 근거, 현장 확인 항목
- 핵심 고민 3가지: 근거가 상담신청·통화·사무실 사진 중 어디인지 표시
- 같은 분야 설치 현장: 사진 DB에서 분야·환경이 비슷한 사진 최대 3장과 이유
- 발송 타임라인: 접수 → 1분 뒤 맞춤 MMS → 상담 때 1장 제안서 → 분야별 폭주기 2주 전 재연락 제안일

==================================================
6. 만드는 홍보물과 소비자 심리 설계
==================================================
(1) 맞춤 MMS 광고 — 같은 분야 현장 사진 1장 + 글
    (광고) 표시 → 회사명·담당자 호칭 인사 → 고객이 한 말 되비추기 → 이렇게 해결해 드립니다(결과 위주 2~3줄)
    → 같은 분야 설치 사례(사진 설명) → 혜택을 앞세운 제안 → 회사 정보(대표번호, 이메일, 홈페이지) → 수신거부
(2) 1장 제안서 — 캡처해 바로 보낼 수 있는 한 장
    인사 → 고객의 말을 큰 따옴표로 → '지금' 대 '티링크 도입 후' → 근거 칩 3개
    → 보내 주신 현장 사진과 설치 가능 형태 → 같은 분야 설치 사례 → "하루 약 ○○원" → 회사 정보, 그리고 함께 보낼 메일
(3) SNS 카드뉴스 6장
    뜨끔한 질문 → 매일 잃는 것 → "문제는 사람이 아니라 구조" 관점 전환 → 바뀐 하루(현장 사진 배경) → 근거 수치·같은 분야 사례 → 혜택 제안과 연락처

적용한 심리 원칙
- 거울 효과: 첫 문장은 고객이 실제로 한 말이나 상황
- 손실 회피: 지금 놓치는 전화, 기록 없는 분쟁, 지친 직원을 장면으로
- 사회적 증거: 같은 분야 설치 사례, 1,000여 기업 도입
- 가격 쪼개기: 월 비용을 하루 비용으로 환산
- 실제 시간 압박만: 폭주 시기, 고객이 말한 예산·도입 시점 (가짜 할인·한정·마감 금지)
- 행동 장벽 낮추기: 요청 대신 혜택을 앞세운 제안 ("사진을 보내 주시면 설치 방법과 예상 비용까지 안내해 드립니다")
- 고객이 이미 사진을 보냈으면 사진 요청 대신 "보내 주신 사진을 보니 ○○ 형태로 설치할 수 있습니다"로 전환

==================================================
7. 신뢰성 장치 (AI가 지어내지 않게)
==================================================
- 제품 설명과 수치는 솔루션정보 시트의 사실만 사용 (예: 인터넷전화 녹취 성공률 99%, 최대 3,000석 구축, 기존 회선 그대로 패킷 미러링 방식, AES256 암호화)
- 금액은 AI가 쓰지 않고 홈페이지 간편 견적 요금표로 계산 (IVR 월 2만/설정 5만, 콜백 월 2만/설정 5만, A·B·C 타입 상담원당 월 3만·2만·1만/설정 30만·최소 3명, 종합리포트 월 10만, 모바일 1 USER 월 2만)
- 회사 정보·연락처는 화면이 고정으로 붙임
- 다른 고객사 이름은 AI에 보내지 않고, 사례는 분야로만 표현
- 모든 결과는 담당자 검토용 초안. 홍보성 문자는 (광고) 표시와 무료 수신거부 안내 포함

==================================================
8. 개인정보와 데이터 처리
==================================================
- 엑셀과 사진은 사용자의 브라우저 안에서만 읽고 서버에 저장하거나 업로드하지 않습니다.
- 생성할 때 AI에는 고른 접수 한 건, 사진 목록(글자), 고객 사무실 사진만 보냅니다.
- 시연 데이터의 연락처·이메일은 가짜 값입니다.

9. 기술 구성
==================================================
- 형태: 단일 HTML 페이지(index.html), claude.ai 아티팩트로 실행
- AI: Claude (아티팩트의 AI 호출 기능, 텍스트 + 이미지 입력, JSON 형식 응답)
- 엑셀 읽기: SheetJS
- 견적·폭주 시기 계산: 페이지 내 규칙
- 디자인: 티링크 홈페이지 색상(네이비·인디고)과 Noto Sans KR

10. 실행 방법
==================================================
1) 데모 링크를 claude.ai에 로그인한 상태로 엽니다. (claude.ai 밖에서 index.html을 열면 화면은 보이지만 AI 생성은 동작하지 않습니다.)
2) GitHub 저장소의 sample.zip을 풀어 tlink_consult_db.xlsx와 photos 폴더를 준비합니다.
3) 데이터 연결에서 엑셀과 사진(폴더 안 전체 선택)을 불러옵니다.
4) 접수함에서 한 건을 고르고 "이 고객 맞춤 홍보물 만들기"를 누릅니다. 처음 한 번 AI 사용 허용 창이 뜹니다.

==================================================
11. 시연 데이터
==================================================
- 가상 접수 15건: 공공·복지, 금융, 교육, 의료, 기업 5개 분야, 상담신청만 / 전화만 / 상담신청+전화가 섞여 있음
- 설치 현장 사진 11장: 티링크 홈페이지 설치 사례(공공·복지 2, 금융 2, 교육 2, 의료 2, 기업 3)
- 솔루션 정보: tlinkcrm.com 솔루션 페이지 6곳(비즈, AI 녹취, 고객관리, 모바일, 티링크 온, 인터넷)과 설치 사례 페이지 기준

12. 아직 못 한 것과 다음 버전
==================================================
아직 못 한 것
- 상담 DB와 사진은 파일로 불러오는 방식이라, 엑셀이 바뀌면 다시 불러와야 합니다.
- 시연용 가상 접수로 동작하며, 실제 고객 대상 발송 성과는 아직 측정하지 않았습니다.
- 문자 발송은 담당자가 복사해 직접 합니다.

다음 버전
- 사내 DB 자동 연동: 홈페이지 상담신청과 티링크 AI 녹취 서버의 통화 기록(STT·요약)을 연락처로 자동 매칭해 접수함에 실시간 반영
- 사진 자동 태깅: 현장 기사가 사진을 올리면 AI가 분야·설치 형태를 붙여 사진목록에 자동 추가
- 발송·성과 연동: 담당자 확인 후 발송하고, 회신·계약 여부를 처리상태에 기록해 문구별 반응 비교
