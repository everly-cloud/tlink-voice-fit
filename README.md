# 티링크 Voice-Fit — 상담을 신청한 그 회사만을 위한 홍보물 생성기

티링크(tlinkcrm.com)에 들어온 **상담신청서 + 문의 통화 녹취(STT) + 고객이 보낸 사무실 사진**을 AI가 함께 읽고,
티링크 6개 솔루션 중 맞는 구성과 설치 형태, 예상 견적을 정리한 뒤
**같은 분야 설치 현장 사진을 넣은 고객 맞춤 홍보물**을 만듭니다.

## 무엇을 만드나

| 결과 | 내용 |
|---|---|
| 고객 진단 | 우선순위(P1~P3), 고객이 실제로 한 말, 담당자 다음 행동 |
| 맞는 솔루션 | 6개 솔루션 중 핵심·추가 제안과 이유 (고객이 고른 관심 솔루션과 다르면 그 이유까지) |
| 추천 구성·견적 | AI가 구성만 정하고 금액은 홈페이지 요금표로 계산. 고객이 계산기로 고른 구성과 비교 |
| 설치 형태 | 고객 사무실 사진을 AI가 보고 스탠드형·렉거치형·미러링스위치허브 중 판단 |
| 발송 타임라인 | 접수 → 1분 뒤 MMS → 상담 때 1장 제안서 → 분야별 전화 폭주기 2주 전 재연락 제안일 |
| 발송물 | ① 맞춤 MMS 광고 ② 1장 제안서(+메일) ③ SNS 카드뉴스 6장 |

발송물은 소비자 심리 원칙(거울 효과, 손실 회피, 사회적 증거, 실제 시간 압박, 혜택을 앞세운 제안)에 맞춰 쓰고,
제품 설명과 수치는 `솔루션정보` 시트에 있는 사실만 사용합니다. 다른 고객사 이름은 쓰지 않고 분야로만 말합니다.

## 구성

```
index.html     화면과 동작 전체 (단일 페이지)
sample.zip     시연 자료: tlink_consult_db.xlsx (가상 접수 15건) + photos/ 설치 현장 사진 11장
```

## 데이터 구조 (상담 DB 엑셀)

| 시트 | 내용 |
|---|---|
| 상담접수 | 한 줄 = 한 건. 접수경로, 회사명, 담당자, 분야, 관심 솔루션 1·2, 문의 내용, 간편 견적 계산기 선택값, 통화녹취(STT), 처리상태 |
| 솔루션정보 | 티링크 6개 솔루션의 소개·기능·근거 수치·잘 맞는 고객·가격 (AI 근거용) |
| 폭주시기 | 분야별 전화 폭주 시작월 (재연락 제안일 계산) |
| 사진목록 | 사진 파일명 ↔ 분야·설치 형태·설명 |

## 실행 방법

1. claude.ai 아티팩트로 `index.html`을 엽니다. AI 호출은 claude.ai의 아티팩트 기능을 사용하므로, claude.ai 밖에서 열면 화면은 보이지만 생성은 동작하지 않습니다.
2. `sample.zip`을 풀고, **데이터 연결**에서 `tlink_consult_db.xlsx`와 `photos` 폴더의 사진을 모두 선택해 불러옵니다.
3. 접수함에서 한 건을 고르고 (필요하면 고객 사무실 사진을 추가) **이 고객 맞춤 홍보물 만들기**를 누릅니다.

파일은 브라우저 안에서만 읽고 어디에도 올리지 않습니다. 생성할 때는 고른 접수 한 건과 사진 목록(글자), 고객 사무실 사진만 AI에 보냅니다.

## 시연 데이터 안내

- 상담접수 15건은 가상 데이터이며 연락처·이메일은 가짜 값입니다.
- 견적은 홈페이지 간편 견적 기준 예시 금액(VAT 별도)입니다.
- 문자의 무료수신거부 번호는 자리 표시 값입니다.
